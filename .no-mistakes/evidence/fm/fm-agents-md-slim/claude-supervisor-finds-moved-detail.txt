**3. Adding a custom `state/<id>.check.sh`**
*Source: AGENTS.md §7 only points to the owner. I opened the header of `bin/fm-check-register.sh` (lines 4–8).*
- **What the script must do:** be an ordinary single-link file with mode 0700. It prints exactly one line only when firstmate should wake, prints nothing otherwise, and finishes before `FM_CHECK_TIMEOUT`.
- **Before the watcher runs it:** run `bin/fm-check-register.sh <id>`. This binds the script's current bytes into `state/<id>.check-trust`. If you edit the script afterwards, the hash no longer matches and the watcher won't run it until you register it again.
- **To retire it:** run `bin/fm-check-unregister.sh <id>`, or teardown for a spawned task. Never remove it with a hand-written `rm`.
